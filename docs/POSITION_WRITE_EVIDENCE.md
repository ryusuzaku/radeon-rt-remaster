# Ordered observed surface-write evidence (v8)

`--position-write-evidence` requires `--position-clear-evidence` and its selected
multi-draw prerequisites. The runner sets `RRT_POSITION_WRITE_EVIDENCE=1`.
Older schemas (v1–v7) and default capture behavior remain available.

This is a bounded history of **observed potential writers and boundaries**, not
complete surface contents or game-frame replay. Native calls and HRESULTs remain
authoritative. No shader/material or depth/blend/stencil replay support is added.

## Writer audit

Hooks are generated by `tools/generate_observers.py` for both D3D9 and D3D9Ex
interfaces, including inherited methods. Unknown QueryInterface interfaces are
already rejected by the proxy; that alone does not establish external coverage.

| Path | Evidence / remaining limitation |
| --- | --- |
| DrawPrimitive, DrawIndexedPrimitive, both UP forms, rectangle/triangle patches | Outcome recorded irrespective of shader/type/target rejection or quota. Only committed selected indexed captures receive an ordinal reference. |
| Clear | Pre-call RT0/depth identity, native outcome and successful clear serial link to v7 payload. Failed calls preserve the previous successful clear; successful oversized clears still invalidate its payload. |
| UpdateSurface, UpdateTexture, StretchRect, ColorFill, ComposeRects | Explicit destination resource lifetime ID and native outcome. Texture IDs do not establish subresource/alias identity. |
| GetRenderTargetData, GetFrontBufferData | Destination writes remain visible even if unrelated to selected target. |
| Surface/texture/cube/volume LockRect/LockBox and unlock | Potential write/access boundaries; readonly locks are also conservatively included. No claim to snapshot modified texels or distinguish successful unlock of a readonly lock. Volume9 lacks Resource9 identity, so its scope remains unknown. |
| Surface GetDC / ReleaseDC | Explicit access boundaries; no GDI pixel reconstruction. |
| GenerateMipSubLevels, AddDirtyRect/Box | Potential implicit writes / dirty-content notifications; void calls carry synthetic S_OK, not a native HRESULT success assertion. |
| SetRenderTarget, SetDepthStencilSurface, state-block Apply | Successful or failed attachment/state boundaries. No MRT binding graph or full state-block semantics recovered. |
| Reset/ResetEx, device/Ex/swap-chain Present | Explicit boundaries, not proven engine frames or preserved swap-chain contents. Swap-chain events have unknown device scope in this journal. |
| ProcessVertices, VB/IB locks | Write geometry buffers, not render surfaces; existing shadow invalidation/copy hooks retain their role. |
| Resource creation/destruction, shared handles, external processes, runtime implicit writes, cursor/overlay display | Not a proven surface-write stream. Always represented by the unobserved-scope gap, never inferred absent. |

Sampling, shader rejection and record limits must never make successful native
writers disappear from this history. A rejected native call is retained with its
failure outcome and does not count as a successful intervening write. Access
boundaries are intentionally conservative: some recorded successful calls make no
pixel change. Unrelated destinations also block a process-wide segment rather than
being dismissed using incomplete alias information.

## Contract

Every v8 draw row, including rejected attempts, carries `write_evidence`:

- `scope: process_observed_calls`, `unobserved: true`: mandatory unresolved external,
  alias/subresource and MRT coverage. A consumer cannot promote this to completeness.
- `through`: last completion serial; `dropped_through`: overwritten prefix endpoint.
  The fixed ring retains the latest 64 events, starting before trigger readiness.
  Overflow is a prefix gap, not a reset to a clean journal.
- `observer_gap`: sticky observer/query/record failure; `overlap`: sticky overlapping
  native-call windows or an in-flight call at serialization. These flags never clear.
- `events`: contiguous retained completion order. Each event contains `serial`,
  `operation`, `device`, `target_id`, `depth_id`, `reset_epoch`, `clear_serial`, `hr`
  and `captured_ordinal` (`-1` for calls without an accepted position capture).

Device calls use pre-call RT0/depth identities, except explicit destination writes,
which use the destination resource ID and depth 0. Resource calls have device 0;
unknown identities use 0. Epoch is pre-call; clear serial is read after the call
and the existing success hook. A reset event therefore describes a boundary, not
a resource in the new epoch. Other devices/resources share the bounded journal.

The current accepted draw must be the final journal event, with matching native
outcome, device/reset, surface/clear identity and capture ordinal. Boundary races
reject capture; journal gaps remain conservative. Completion order is insufficient
to infer native ordering when calls overlap. No concurrency qualification is claimed.

The reader validates exact shapes, integer types/ranges, operation vocabulary,
window size/order, matching capture references, immutable repeated events and
sticky gaps. Import preserves the complete JSON in immutable candidates. Existing
16 MiB ledger / 4096 attempts / 16 captures / 4 per interval / 120 Presents limits
still apply. Repeating history on rejected rows may reach the byte limit earlier.

## Admission and validation

`write_coverage.observed_segment` distinguishes `captured_draws_only`, `gapped`
and `unavailable`. It searches for the exact retained successful clear anchor and
lists intervening captured ordinals and unsupported event serials. A dropped prefix
does not erase a later retained clear anchor, but remains explicitly reported.
This is only local observed-call evidence, including clear candidates that may
be partial or otherwise inadmissible; v7 initial-content checks still apply.

`complete_surface_write_coverage` and `ready_for_stateful_replay` are always false;
`initial_contents` remains unknown. Grouped reports include per-draw admission so
later gaps cannot be hidden by the first draw's assessment. Diagnostic grouped
replay retains its own clear and depth/blending-off raster policy.

Native controls exercise captured-only segments, failed draws/fills, all four
regular draw forms, identical native shader execution outside exact-hash admission,
fill/readback/lock writes, attachment changes, reset epochs, and 70 writes that
exhaust the 64-event window. They retain the existing exact native/CPU position
raster comparison. Reader negatives cover fabricated coverage, changed history,
invalid references/outcomes/order/endpoint/bounds and legacy-schema impersonation.
Overlap/observer-gap reporting is checked synthetically; native concurrent calls
and allocation failure are not induced or claimed as qualified.

to qualify a closed single-target fixture scope: tracked subresource aliases,
MRT/shared-resource exclusion and writable-access lifetimes, then explicitly
supported state-aware native/CPU replay. Once that contract has meaningful admitted
